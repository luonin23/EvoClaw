The Engines

六大智能引擎协同运转

每一个引擎独立运行、协同配合，形成完整的交易闭环。 从选币到盈利，全链路自动化。

01

利润收割引擎

5 档阶梯式止盈，盈利达不同阶段自动分批平仓。 低位利润先落袋，高位仓位继续博弈，最大化资金利用率。

02

全局风控引擎

账户整体盈利达设定阈值时一键全平所有持仓， 落袋为安后自动重新开仓，资金永不闲置。

03

对冲锁定引擎

同币种多空双边同时盈利时，智能判断最佳对平时机， 双向平仓锁定对冲利润，释放保证金给下一轮建仓。

04

成本修复引擎

仓位浮亏达预设条件时自动追加仓位摊薄平均成本， 基于当前持仓量动态计算加仓规模，非固定模式灵活应对。

05

仓位自愈引擎

持续监测持仓完整性，发现缺失仓位自动补齐。 三重防重复机制确保不会过度开仓，停补保护防止逆势加仓。

06

数据可视化引擎

持仓热力矩阵一屏尽览全局战场，多空盈亏实时统计， 盈利趋势 Canvas 图表，让数据成为你指挥交易的作战地图。

What's New

v2.1 全新升级

不仅是交易引擎的迭代，更是工程体系的全面进化。

☢

爆仓检测

实时监控 Binance 强平事件，Top10 爆仓排行 + 历史事件时间线。 每次爆仓触发 PnL 快照，清楚了解极端行情的真实代价。

⚡

智能熔断

针对 Binance -2027 错误（超出最大持仓）内置断路器模式。 连续失败 5 次自动跳过 10 分钟，成功后自动恢复，避免死循环重试。

⛁

配置数据库化

交易配置从 JSON 文件迁移至 SQLite 数据库统一管理。 所有参数可编辑、可追溯、可通过 Web API 实时修改，无需重启进程。

☰

日志限流

错误日志独立分流（errors.log），WARNING+ 级别单独记录。 旋转日志 3MB/5 备份 + 启动时自动清理旧文件，磁盘永不溢出。

★

API 缓存机制

高频接口 15 秒 TTL 缓存防 Binance 418 封禁。 asyncio.Lock 防缓存击穿，缓存键按时间粒度区分保证数据新鲜度。

☷

看门狗守护

restart.sh --watch 模式每 30 秒检测进程存活。 崩溃自动重启 + crash 前最后 10 行日志写入 crash.log，永不掉线。

☐

PID 文件锁

fcntl.flock 防双进程同时运行，避免重复开仓酿成灾难。 restart.sh 优雅关闭：SIGTERM 8 秒等待后再 SIGKILL。

⚖

停补安全加固

should_stop_replenish() 统一检查所有开仓路径。 价格不可获取时默认 STOP，从源头杜绝无限开仓安全漏洞。
