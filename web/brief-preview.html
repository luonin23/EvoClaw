Design Notes

  • Light theme is recommended for the marketing landing page (intro.html).
  • Dark theme is recommended for the trading terminal (index.html) to reduce eye strain during long monitoring sessions.
  • Accent color #00d084 is shared across both themes, matching Fuselab's bright green signature.
  • All JavaScript logic, API calls, Canvas chart rendering, and the matrix heatmap algorithm will remain unchanged during implementation.
  • Hover effects use subtle translateY(-2px) — no scale or rotate on images.
